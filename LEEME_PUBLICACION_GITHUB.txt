NAXVO - paquete seguro para GitHub

Este paquete excluye intencionalmente:
- backend/.env (contiene credenciales/tokens)
- node_modules y .expo
- archivos privados y cargas de usuarios
- volcados SQL con datos de demostracion completos
- archivos de credenciales demo

Se conservan .env.example, el codigo fuente y las migraciones de esquema 001-012.
Nunca subas el .env real ni tokens/contraseñas a GitHub.
